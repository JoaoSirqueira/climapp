# 🌦️ ClimApp

O **ClimApp** é um aplicativo simples e intuitivo para consultar informações meteorológicas em tempo real. Ele permite visualizar temperatura atual, condições climáticas, velocidade do vento, umidade e previsão dos próximos dias, utilizando uma API de clima confiável.

---

## 🚀 Funcionalidades

- 🌍 Consulta do clima por cidade  
- 📡 Dados atualizados em tempo real  
- 🌡️ Exibição de temperatura, sensação térmica e umidade  
- ☁️ Condições do tempo (chuva, nublado, ensolarado etc.)  
- 📅 Previsão para 3 ou 5 dias  
- 🎨 Interface moderna e responsiva  
- ⚡ Alto desempenho e carregamento rápido  

---

## 🛠️ Tecnologias Utilizadas

- React / React Native (dependendo da versão do projeto)  
- API de Clima (OpenWeather, WeatherAPI ou outra)  
- Axios ou Fetch para requisições  
- Styled Components / CSS / Tailwind (conforme o projeto)
